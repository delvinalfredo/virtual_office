# Stack Context

Before implementation, identify:

1. Runtime/language and versions.
2. Framework and package manager.
3. Application entry points.
4. Database and migration system.
5. Queue/cache/search systems.
6. External APIs and authentication mechanisms.
7. Test/build/lint commands.
8. Container/deployment setup.

Record only facts verified from the repository. Do not invent versions or infrastructure.
